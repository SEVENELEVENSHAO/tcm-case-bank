# TCM Case Bank

A searchable, self-contained viewer for 1,229 traditional Chinese medicine case records.

The records retain their source labels and source locators where available. This is a study and reference collection, not clinical guidance. Records and extracted source text may still require review against the cited originals.

## Open locally

Open `index.html` in a modern browser. No server or build step is required.

## Publishing

GitHub Actions deploys the repository root to GitHub Pages whenever `main` is updated.
